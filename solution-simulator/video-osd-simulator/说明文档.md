# video-osd-simulator 说明文档

`video-osd-simulator` 用于联调 ZLMediaKit、视频推流与 OSD 数据回放。当前版本支持：

- `RTMP`、`RTSP` 继续通过 `ffmpeg` 推流。
- `WEBRTC` 通过外部推流命令执行，Spring Boot 负责任务编排和进程管理。
- OSD 数据可从 `device_telemetry_sub` 表读取，也保留 JSON 上传、Excel 导入能力。
- 任务启动时可以同时触发视频推流和按 `publish_time` 时间范围回放 OSD 数据。

## 当前模块职责

`video-osd-simulator-core`

- `FfmpegCommandBuilder`：生成 RTMP、RTSP 推流命令。
- `ExternalWebRtcCommandBuilder`：根据命令模板生成 WebRTC 推流命令。
- `StreamTaskRuntime`：维护外部推流进程状态。
- `VideoSourceScanner`：扫描本地视频文件。
- `OsdPayloadSupport`：把结构化字段和 `raw_json` 合并成最终 OSD JSON。

`video-osd-simulator-sample`

- 任务表 `sim_stream_task` 的 CRUD 与启动、停止、状态查询。
- OSD 表 `device_telemetry_sub` 的 CRUD、JSON 上传、Excel 导入。
- `application.yml` 提供本地 H2 默认配置。
- `application-mysql.yml` 提供对接 `xm_test` 的 MySQL 示例配置。

## MySQL 配置

使用 MySQL 时启用 `mysql` profile：

```bash
mvn -pl solution-simulator/video-osd-simulator/video-osd-simulator-sample -am spring-boot:run -Dspring-boot.run.profiles=mysql
```

示例配置文件为 [application-mysql.yml](D:/workspace/github/solution-hub/solution-simulator/video-osd-simulator/video-osd-simulator-sample/src/main/resources/application-mysql.yml:1)，其中数据库指向：

- 库：`xm_test`
- 表：`device_telemetry_sub`
- URL：`jdbc:mysql://localhost:3306/xm_test?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai`

## 关键配置

```yaml
simulator:
  osd:
    websocket-endpoint: ws://127.0.0.1:18083/osd
    fixed-interval-millis: 1000
    publish-time-start: 2026-06-29T10:00:00
    publish-time-end: 2026-06-29T10:30:00
  video:
    source-directory: ./sample-videos
    source-file: ./sample-videos/demo.mp4
  zlm:
    host: 127.0.0.1
    rtmp-port: 1935
    rtsp-port: 554
    rtc-port: 8080
    app: live
    stream: drone001
  webrtc:
    push-command-template: webrtc-pusher --input "{videoFile}" --host {zlmHost} --app {app} --stream {stream}
```

说明：

- `publish-time-start` 和 `publish-time-end` 用于限定 OSD 回放时间窗。
- `source-file` 优先于 `source-directory + file-pattern`。
- `push-command-template` 由外部 WebRTC 推流工具消费，当前应用只负责拼装命令和拉起进程。

## 任务表字段建议

`sim_stream_task` 当前除原有字段外，新增：

- `video_file_path`
- `webrtc_command_template`
- `osd_publish_time_start`
- `osd_publish_time_end`

这样可以做到“先插入任务，再启动任务”，每条任务独立控制视频源、协议和 OSD 时间范围。

## 启动示例

新增一个 WebRTC 任务：

```bash
curl -X POST http://localhost:18083/simulator/stream-task/add ^
  -H "Content-Type: application/json" ^
  -d "{\"taskName\":\"demo-webrtc\",\"videoFilePath\":\"./sample-videos/demo.mp4\",\"zlmHost\":\"127.0.0.1\",\"zlmPort\":1935,\"app\":\"live\",\"stream\":\"drone001\",\"protocol\":\"WEBRTC\",\"webrtcCommandTemplate\":\"webrtc-pusher --input \\\"{videoFile}\\\" --host {zlmHost} --app {app} --stream {stream}\",\"osdPublishTimeStart\":\"2026-06-29T10:00:00\",\"osdPublishTimeEnd\":\"2026-06-29T10:30:00\"}"
```

启动任务：

```bash
curl -X POST http://localhost:18083/simulator/stream-task/start/1
```

停止任务：

```bash
curl -X POST http://localhost:18083/simulator/stream-task/stop/1
```

查询状态：

```bash
curl http://localhost:18083/simulator/stream-task/status/1
```
